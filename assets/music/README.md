# Wedding Music Assets

You can add your preferred background music file here.

### How to use your custom audio:
1. Save your MP3 file as:
   `assets/music/ambient.mp3`
2. The web application checks for `assets/music/ambient.mp3` automatically when the music button (♪) is clicked.
3. If no MP3 file is present, the app automatically falls back to an elegant built-in Web Audio API ambient acoustic synthesizer (harp & acoustic sitar chords) so the music toggle works smoothly out of the box!
